MINT: UNBLOCK CAR PUZZLE

隐私政策

我们希望你把注意力留给谜题。这里说明 Mint: Unblock Car Puzzle（汽车突围）及本网站如何处理数据。

更新及生效日期：2026 年 10 月 8 日适用于 iOS 版本 · 广告 / Game Center

先说你最关心的

游戏无需注册开发者账号，关卡存档保存在设备上。自愿观看广告时会使用 Google AdMob；登录 Apple Game Center 后会同步累计星数和成就；启动时会获取公开的远程配置。下面分别说明这些功能涉及的数据与隐私选择。

01适用范围与开发者

本政策适用于由 Jocelyn 提供的 Mint: Unblock Car Puzzle（薄荷汽车突围） iOS 版本（应用标识：com.simple.game.mint），以及本隐私政策网站。

游戏无需注册开发者账号。基础关卡进度保存在设备上；激励广告、Apple Game Center 和远程配置需要联网。Google、Apple、GitHub 作为第三方服务提供方，按其各自的隐私政策处理相关数据。

02游戏中的数据

我们没有用于接收玩家存档的自建服务器，也没有另外集成行为统计 SDK。下列信息保存在应用的设备存储中：

本地信息用途
关卡成绩、最高星级、最佳步数、徽章进度继续闯关、计算解锁和累计星数；启用 Game Center 后，另向 Apple 提交累计星数与成就进度
体力、恢复时间及奖励状态计算体力恢复、处理广告奖励
语言、音乐、音效、震动和引导设置保存偏好；初次使用时参考设备语言
远程配置缓存保存最近取得的有效功能配置，以便网络不可用时继续启动

广告和 Game Center 所涉及的信息见下文。我们不要求玩家提供真实姓名、电话号码或通讯录。

03激励广告与隐私选择

游戏接入 Google AdMob（Google Mobile Ads SDK）提供自愿观看的激励广告：体力少于 30 时，看完一次可获得 5 点体力（最高 30）；每次使用撤销或主动提示也需要完成一次相应广告。提前关闭或未获得有效奖励回调时，不发放奖励或执行该操作。

据 Google 的 SDK 数据说明，广告服务可能处理 IP 地址（包括据此估计的大致位置）、设备或广告标识符、广告展示及互动信息，以及崩溃日志和性能诊断数据，用于广告投放、衡量和服务运行。实际处理取决于 SDK、地区、设备设置与适用的隐私选择。我们不会为广告主动读取你的精确定位、照片、通讯录或麦克风。

适用时，游戏通过 Google 的同意管理流程展示隐私选项；若该服务要求提供再次管理的入口，游戏设置中会显示广告隐私选项。广告标识符的访问受 iOS 权限控制，未经系统所要求的跟踪授权不能访问 IDFA。你也可在 iOS 的“设置 → 隐私与安全性 → 跟踪”中管理应用跟踪权限。拒绝跟踪不代表广告服务完全不处理数据。

详见 Google 隐私政策及 Google Mobile Ads SDK 数据说明。

04Apple 排行榜与成就

iOS 版本通过 Apple Game Center 提供一个累计星数排行榜（最高 297 星）和 10 项阶段成就。游戏启动时可能发起 Game Center 认证；认证成功后，将累计星数和阶段成就完成百分比提交给 Apple。Game Center 会处理与 Apple 账户关联的玩家身份、游戏活动、分数和成就。

你的 Game Center 昵称、头像和排行榜成绩可能对其他玩家可见；活动和成就的可见范围由 Apple 服务规则及你的个人资料设置决定。你可以在系统 Game Center 设置中管理登录和隐私。游戏不请求好友列表，也不获取 Apple 账户密码。

登录 Game Center 和 iCloud 且启用 iCloud 云盘后，游戏会通过 Apple 游戏存档服务，将逐关成绩、最高星数和最佳步数备份到你的私有 iCloud 容器，合并不同设备的最佳成绩，并在重装后恢复此前已上传的进度。体力及偏好设置仍保存在本地。退出 Game Center 后可以继续本地闯关，但排行榜和成就同步需要认证与网络。详见 Apple Game Center 与隐私。

05启动配置与网络访问

游戏加载时通过 HTTPS 从 GitHub 托管的公开配置文件读取广告服务配置和隐私政策地址，并在设备上缓存有效结果。该请求不附带你的关卡存档、累计星数、Game Center 玩家标识或电子邮箱。网络不可用时使用可用缓存或内置默认配置。

网络请求仍会向托管服务传递连接所需的 IP 地址及请求信息；GitHub 可能按照其隐私声明保存服务和安全日志。读取配置与展示广告、提交 Game Center 成绩是不同的网络活动。

06保存、删除与安全

本地存档保存在 iOS 应用存储中。在系统中“删除 App”通常会删除设备上的应用数据；“卸载 App”（保留文稿与数据）不等同于删除存档。系统备份、设备迁移或恢复可能保留或恢复数据，取决于你的 Apple 设备和备份设置。我们无法从自建服务器恢复存档。

删除游戏不会自动删除 iCloud 云存档或 Apple Game Center 已保存的成绩、成就或 Google 已处理的数据。第三方数据的保留期限和删除方式由各服务政策决定，请通过 Apple 或 Google 提供的隐私工具管理，也可以联系我们咨询。

我们依靠操作系统的应用存储隔离保护本地文件，并使用 HTTPS 获取远程配置。任何存储或传输方式都无法保证绝对安全。第三方服务可能在你所在地区以外处理数据，具体地点和保障措施见其隐私政策。

07本网站与外部链接

本网站由 GitHub Pages 托管，页面没有添加广告 SDK、统计脚本、追踪 Cookie 或浏览器本地存储；字体使用系统字体，样式和图标随本仓库提供。

GitHub Pages 会出于安全目的记录访问者 IP 地址。详见 GitHub Pages 说明和 GitHub 隐私声明。点击外部链接后，目标服务按自己的政策处理访问数据。

08联系信息与隐私请求

主动发送邮件时，我们会收到你的邮箱地址、邮件内容及你选择提供的附件，仅用于回复问题、提供支持及处理隐私请求，不用于营销。邮件由邮箱服务商处理；我们在处理请求及后续问题所需期间保留通信，之后删除，法律要求保留的情形除外。

根据适用法律，你可以联系我们申请查阅、更正或删除我们持有的信息，或提出与数据处理有关的其他请求。对于由 Apple、Google 或 GitHub 直接控制的数据，请同时使用相应服务的隐私渠道。请勿发送与问题无关的敏感信息。

09儿童隐私

游戏不要求儿童提交姓名、邮箱或联系方式，但联网广告和 Game Center 可能处理上文列明的信息，因此本版本并非完全不处理数据的离线应用。监护人可通过 Apple 的家庭和隐私设置管理儿童对相关服务的使用。

如果你认为儿童向我们提供了不应保留的个人信息，请通过下方邮箱联系，我们会核实并处理删除请求。第三方服务对儿童账户的适用规则请参阅各自的政策。

10政策更新

功能或数据处理方式发生变化时，我们会更新本页及生效日期，并在适用法律要求时提供相应通知或取得必要同意。
